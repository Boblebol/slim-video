# 📦 Open-Source Readiness Skill

Transforms any repository into a welcoming, strictly maintained open-source standard.

---

## 📑 Required Repository Assets

- [ ] **`README.md`**: Badges (CI, License), Pitch, Architecture (Mermaid), Quickstart, Dev guide (`make dev`, `make test`), Project Layout.
- [ ] **`CHANGELOG.md`**: Follows [Keep a Changelog 1.1.0](https://keepachangelog.com/) with Semantic Versioning (`## [Unreleased]`, `### Added`, `### Fixed`).
- [ ] **`LICENSE`**: MIT / Apache-2.0 / AGPL-3.0.
- [ ] **`CONTRIBUTING.md`**: Git workflow, PR rules, commit style, testing requirements.
- [ ] **`CODE_OF_CONDUCT.md`**: Contributor Covenant v2.1.
- [ ] **`.github/PULL_REQUEST_TEMPLATE.md`**: Standard PR template with Mermaid diagrams.
- [ ] **`.github/ISSUE_TEMPLATE/`**: Bug report and Feature request templates.
